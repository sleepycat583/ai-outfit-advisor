# R-001 修复测试报告

## 修复内容

为 `VectorStoreService` 添加了自动知识库恢复功能，解决了问答页首次启动时知识库为空的问题。

## 代码变更

### 文件：`src/services/vector_store.py`

**新增方法**：
1. `_is_empty()`: 检查知识库向量索引是否为空
2. `_rebuild_knowledge_base()`: 触发知识库恢复（种子导入 + Supabase 恢复）

**修改逻辑**：
- `__init__` 方法在初始化 Chroma 后，自动检查索引是否为空
- 如果为空，调用 `_rebuild_knowledge_base()` 触发恢复
- 复用 `KnowledgeBaseService` 的恢复逻辑，保持代码 DRY 原则
